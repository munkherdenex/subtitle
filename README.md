# Англиас монгол хадмал орчуулагч

Англи `.srt` эсвэл SRT хэлбэрийн текст агуулсан `.docx` файлыг Монгол хэл рүү орчуулдаг жижиг хувийн веб апп. Орчуулгыг сервер талын API route Anthropic Claude-оор гүйцэтгэнэ; Anthropic API түлхүүр хөтөч рүү илгээгдэхгүй. Хэрэглэгчийн бүртгэл болон өгөгдлийн сан ашиглахгүй.

## Шаардлага

- Node.js 20.9 буюу түүнээс дээш
- Anthropic API түлхүүр

## Орон нутагт ажиллуулах

1. Хамаарлуудыг суулгана:

   ```bash
   npm install
   ```

2. `.env.example` файлыг хуулж `.env.local` нэрлээд утгуудаа бөглөнө:

   ```dotenv
   ANTHROPIC_API_KEY=your_anthropic_api_key
   APP_PASSWORD=choose-a-private-password
   ```

   `APP_PASSWORD` нь орчуулгын API-г зөвшөөрөхөд ашиглагдах тул таамаглахад хэцүү утга сонгоорой.

3. Хөгжүүлэлтийн серверийг эхлүүлнэ:

   ```bash
   npm run dev
   ```

4. `http://localhost:3000` хаягаар нээнэ. Туршилт болон TypeScript шалгалтыг `npm test`, `npm run typecheck` командаар тус тус ажиллуулж болно.

## Vercel-д байрлуулах

1. Энэ GitHub репозиторыг Vercel-д холбоно.
2. Vercel төслийн **Settings → Environment Variables** хэсэгт дараах хоёр хувьсагчийг нэмнэ:
   - `ANTHROPIC_API_KEY` — Anthropic API түлхүүр
   - `APP_PASSWORD` — аппыг ашиглах нууц үг
3. Хувьсагчийг Production болон ашиглах шаардлагатай Preview/Development орчинд тохируулна.
4. Репозиторыг deploy хийнэ. Environment Variables өөрчилсний дараа шинэ deployment ажиллуулах шаардлагатай.

Орчуулах бүрд хөтөч `APP_PASSWORD` утгыг `x-app-password` хүсэлтийн header-д илгээнэ. Зөв нууц үгийг анх амжилттай орчуулсны дараа тухайн төхөөрөмжийн `localStorage`-д хадгалдаг тул итгэлгүй төхөөрөмжид бүү ашиглаарай.

## Ашиглалт

- `.srt` эсвэл SRT агуулсан `.docx` сонгох/чирж оруулна.
- **Зөөлрүүлсэн** эсвэл **Үнэнч** өнгийг сонгоно. Киноны тухай товч мэдээлэл нэмж болно.
- **Орчуулах** товч дарж, дууссаны дараа урьдчилсан харагдац шалган `.mn.srt` файлаа татна.

Хадмал 60 мөрөөр багцлагдан дарааллаар орчуулагдана. Нэг багцын хүсэлт хоёр хүртэл удаа автоматаар дахин оролдоно; алдаатай багцыг дэлгэцээс дахин ажиллуулж болно. Гаралтын индекс болон хугацааг эх файлаас хуулж, UTF-8 болон CRLF мөрийн төгсгөлөөр хадгална.
